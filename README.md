# MessagingApp

This is an answer to the coding task

1. It covers from point 1 until 7 in task.
2. Java 21 is used, so I used records and virtual threads.
3. As asked, this project is a maven project which can do and check the formatting , execute the main classes.
4. To run point 5 please execute run_thread_based.sh.
5. To run point 7 please execute run_socket_based.sh.
6. The correct output should be a message on console saying

"initiator - sentCount=10 receivedCount=10
player2 - sentCount=10 receivedCount=10
Finished execution thread based messaging."

Then everything is fine, Otherwise please clean the caches an execute mvn clean and then execute the scripts.
